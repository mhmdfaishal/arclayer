# Architecture

How the ArcLayer code is organised, which module may import which, and where new code belongs. These documents describe the code as it is today. The original plan, which differs in places, is under [development](../development/README.md).

| Document | Read it when |
|---|---|
| [layout.md](layout.md) | You want a map of the repository and the package |
| [dependency-rules.md](dependency-rules.md) | You are about to add an import and want to know whether it is allowed |
| [incident-flow.md](incident-flow.md) | You want to follow one fault from the host to a policy update |
| [persistence.md](persistence.md) | You want to know what is stored in the database and why |
| [extending.md](extending.md) | You are adding a candidate, policy, storage backend, gate rule or embedding model |
