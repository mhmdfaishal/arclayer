# Evaluation

This folder holds the plan for evaluating ArcLayer: test hosts, fault injection, the experiment harness, and the statistical analysis.
The evaluation code does NOT live in this repository. It lives in the sibling project `projects/evaluation`, which imports ArcLayer.

- [test-hosts-and-fault-injectors.md](test-hosts-and-fault-injectors.md): the synthetic and reference hosts, the six fault injectors, and the conditional StateMAS adapter.
- [experiment-harness.md](experiment-harness.md): experiment configuration, task split, calibration, and the outcome matrix and online modes.
- [statistical-analysis.md](statistical-analysis.md): metrics, statistical tests, power analysis, and report generation.
