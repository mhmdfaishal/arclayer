# Process

This folder records how the work on ArcLayer was planned and tested: the phased task plan, the testing strategy, and the security and ethics constraints.
Each file is a translation of the corresponding section of the original implementation plan.

- [implementation-phases.md](implementation-phases.md): Phases 0 to 7 with task tables, first tests, and milestones M1 and M2.
- [testing-strategy.md](testing-strategy.md): test layers, coverage, tools, and the rule against real LLM calls in automated tests.
- [security-and-ethics.md](security-and-ethics.md): isolation, secret handling, gate and allowlist enforcement, and cost limits.
